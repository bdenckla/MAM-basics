# Provenance of the Holman ketiv/qere review data

`table_data.json`, `introduction.md`, and `gh-pages/holman/img/` were extracted
from Daniel Holman's *Review of Qere and Kethib readings in the Aleppo and
Leningrad*.

The review document entered `holman-ketiv-qere` at commit `f7f47bc` on
2026-04-04.  The extracted source data first landed there at commit `6ddee50`
on 2026-04-10.  The extractor's final source-repository name was
`py/main_extract_docx_and_render_table.py`, established at commit `e11d14f` on
2026-04-14.

The document is no longer a live input.  The exact document and the former
extraction command remain in the `holman-ketiv-qere` Git history; the tracked
data here is verified and rendered by `py/main_verify_and_render_table.py`.
