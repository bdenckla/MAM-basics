Taamey D 1.2

These notes list the changes since Taamey D 1.1, published on
2026-10-27. Each release replaces this file with its own notes.

This is the first release of Taamey D built and published from the
MAM-basics repository. Taamey D's sources, build, shaping checks and
release tool moved there from the hbofonts repository on 2026-10-28
and 2026-10-29.

Changes

- The version number is now 1.2, and the font's unique-ID name ends
  with it.
- Nothing else in the font changes: no glyph, character, outline,
  advance width, vertical metric or OpenType feature differs from
  1.1, so text is shaped and rendered as it was in 1.1.
- The corresponding-source archive holds the font's sources and its
  build at their paths in MAM-basics. From the directory into which
  it is extracted, the build is:
    python py/main_taamey_d_build.py
  It needs FontForge, with its Python module and WOFF2 support.
