Isaiah’s four editorial decisions — which categories contain them?

The Introduction calls four cases “the first three types,” but its preceding list puts four cases in the first two types. The section “Isaiah as an example of applying the method” divides unusual readings into five types. Type 1 is a doubtful letter at Isaiah 10:15; type 2 contains three pointing or accent questions. Type 3 adds two separate pointing anomalies. The first two types contain 1 + 3 = 4 places. The first three contain 1 + 3 + 2 = 6. The four decisions that follow concern Isaiah 10:15, 55:5, 45:6 and 14:2, matching the first two types. This is a grouping description error, rather than a reconsideration of the editorial decisions. Determine whether “first two types” is the intended wording; the listed decisions support that reading.
