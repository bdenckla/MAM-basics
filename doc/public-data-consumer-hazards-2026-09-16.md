# Public-data consumer hazards audit, 2026-09-16

State: finished audit. This receipt covers the main-reachable history through
`dcc0d61d773df62fa73adcdd4bbe51dd4479d3fe`. Corrections belong in
`public-data-consumer-hazards-2026-09-16-update.md`; do not edit this file after its

## Scope and method

The audited root is `d86e577936bcec64dbdd8ddd298b4ed2fbefe177`, dated 2026-03-09.
The audited history contains 2,486 commits, so the entire reachable history falls in
Ben Denckla's requested period beginning 2026-01-01.

The audit read the subject and body of every reachable commit. A first pass selected
1,260 messages by hazard terms and 412 commits by paths that produce, read, document,
or verify MAM-parsed, MAM-simple, and the three codex entry indexes. The union was
1,432 commits. A second pass intersected the relevant paths with high-signal language
for silent loss, contamination, duplication, choices, representation, segmentation,
sparse storage, mark order, locators, and transcription. The second pass inspected
the changed paths and matching diff lines of 101 commits. The accepted items below
were then checked against their complete commit messages and relevant diffs, the
current schemas, every currently recognized plain and plus template, the current
closed dispatches, and the public format documentation.

The broad pass deliberately over-selected. It rejected build and dependency failures,
provenance-only changes, generated-page presentation bugs, retired example programs,
the Google-derived MAM-parsed product, historical release snapshots, and failures
whose only audience is a MAM-internal reproducer. Those items do not justify a warning
inside a current public payload. The Google-derived product remains governed by
`doc/PLAN-retire-google-sheet.md`.

## Decisions recorded on 2026-09-16

Ben decided that this undertaking audits the entire main-reachable AI-era history and
adds adjacent documentation and concise payload notices for current MAM-parsed,
MAM-simple, and codex-index data. It excludes the Google-derived MAM-parsed product.
It distinguishes content choices, representation choices, structural roles, and
segmentation. Public mark-order guidance describes interoperability consequences;
MAM's internal work retains the stronger no-normalization rule. The Leningrad,
Aleppo, and Cambridge entry-index schemas may change without compatibility shims.

An atom is one written form between spaces or maqafs. A chanted word is one atom or a
complete maqaf compound, the unit on which cantillation operates. Payload boundaries
do not define either unit.

## Ten accepted hazards

1. **Generic parameter walking contaminates Scripture and can duplicate a
   representation.** Commit `147e9e4fb52655203b042aa909521c6d755ec04e`,
   “Dispatch on what a template MEANS, not on whether it carries parameters,” changed
   `py/hkq_cmn/mam_plus_verse_data.py:_collect_text_fragments`. Navigation, book-title,
   parashah-marker, and documentation parameters had entered running Scripture; the
   special-letter wrapper had contributed two representations of the same atom-form.
   Commit `2f8c04269196989bcc9ce0427b67cb8f3325a9b4`, “near-aleppo: the shared
   render() flattens marker text into Scripture, and what that moves,” independently
   found the same failure shape in a later generic walker. The current prevention is
   the named role dispatch in `py/mb_cmn/template_names.py` and the closed collector.
   The current documentation anchor is “Selected templates” in
   `gh-pages/MAM-parsed/plain/html/mpplain.html`. Failure mode: contamination and
   duplication. Audience: generic external consumers and MAM-internal reproducers.
   Destination: embedded MAM-parsed notice and adjacent MAM-parsed and MAM-simple
   documentation.

2. **Incomplete dispatch silently omits Scripture.** Commit
   `1ef8f514f90f36bb631435e987f11aa06ee8fc2e`, “vers-and-cant strands: keep
   top-level ketiv/qere words (fix #199),” changed
   `py/versification_and_cantillation/strands.py:_strand_word_text`: a top-level
   ketiv/qere template fell through and its qere disappeared. The current prevention
   is closed template validation and explicit projection in
   `py/hkq_cmn/qere_projection.py`. The current documentation anchors are “Ketiv/Qere”
   and “Extracting the plain text of a verse” in
   `MAM-simple/doc/reading-mam-simple-xml.md`. Failure mode: omission. Audience: both.
   Destination: embedded MAM-parsed and MAM-simple notices and adjacent documentation.

3. **A special-letter wrapper contains two representations of one atom-form, not two
   Scripture branches.** The duplication found in
   `147e9e4fb52655203b042aa909521c6d755ec04e` was possible because the detailed
   children and the uninterrupted description both spell the atom-form. Commit
   `73c6b1137777ad1a522949fcea290f8ac1f87a7b`, “Restore special-letter wrappers in
   documentation text,” changed `py/mpplus/mpplus_slh_words.py` and regenerated both
   public products, confirming that the wrapper can also occur inside documentation
   and note contexts. The current documentation anchors are “Special letter templates”
   in `gh-pages/MAM-parsed/plain/html/mpplain.html` and “Suspended-letter words:
   `<slh-word>`” in `MAM-simple/doc/reading-mam-simple-xml.md`. Failure mode:
   duplication. Audience: generic external consumers. Destination: both embedded
   notices and adjacent documentation.

4. **A downstream projection can remove a content choice before an analysis sees it.**
   Commit `1861203801d599ce7e20ce5a55b1dccbfd0d0006`, “Psalms 71:9 WAS WRONGLY
   CALLED a Phonetic MAM defect; the correction names MAM's stress-variant template
   and MAM-simple's policy,” corrected a conclusion drawn from MAM-simple after that
   product had selected the first stress-helper branch. MAM-parsed retains the choice;
   MAM-simple deliberately resolves it. The current documentation anchors are “Choice
   templates” in `gh-pages/MAM-parsed/plain/html/mpplain.html` and “The three
   cantillations: `<cant-all-three>`” in
   `MAM-simple/doc/reading-mam-simple-xml.md`. Failure mode: category error and
   omission relative to the wrong source. Audience: generic external consumers.
   Destination: embedded MAM-parsed notice, format-specific MAM-simple notice, and
   adjacent documentation.

5. **Structural boundaries are not segmentation boundaries.** Commit
   `2716e90e7fcccbd6a7b1d21d23131cbf1f9564d1`, “Fix #215: fold MAM-simple's lone
   U+05C0 onto the atom it follows,” changed
   `py/accgram/chanted_word_accents.py:_fold_lone_bars`. A standalone paseq/legarmeh
   element had been treated as a space-delimited chanted word. The remedy joined the
   mark to the preceding atom before segmentation; it did not redefine an XML element
   as a unit of cantillation. The current documentation anchor is “Legarmeh and paseq”
   in `MAM-simple/doc/reading-mam-simple-xml.md`. Failure mode: premature
   segmentation. Audience: generic external consumers. Destination: both embedded
   notices and adjacent documentation.

6. **An absent BHS or Sefaria MAM-simple file means fallback, not an absent book.**
   Commit `6dbd27e74cd01e43b18551384ba36edc7a7c6363`, “One MAM-simple book-group
   resolver, and it raises,” changed `py/accgram/mam_simple_verse.py`. A second reader
   skipped absent incremental files and reported a successful empty result. The current
   prevention is the single raising resolver. The current documentation anchor is “The
   BHS and Sefaria folders are incremental, with the MAM ones as the base” in
   `MAM-simple/doc/reading-mam-simple.md`. Failure mode: omission. Audience: generic
   external consumers and MAM-internal reproducers. Destination: embedded MAM-simple
   notice and adjacent documentation.

7. **MAM mark order can defeat literal search and byte round trips without a visible
   difference.** Commit `73ab83832de9d0a6ba92f9f2cea52a62548c5057`, “Put
   hand-authored prose Hebrew back in MAM-normal mark order,” repaired 116
   Unicode-normal-order clusters that rendered identically. The public hazard is not
   a universal prohibition: normalized search input can miss equivalent-looking MAM
   text, and normalization changes bytes when a literal round trip or MAM-compatible
   output is required. MAM's internal prohibition remains stronger. The current
   documentation anchor is “MAM-normal order for Hebrew marks” in
   `doc/mam-normal-mark-order.md`. Failure mode: byte change and failed literal
   equality. Audience: generic external consumers and MAM-internal reproducers.
   Destination: both embedded notices and adjacent documentation; the stronger rule
   remains internal.

8. **MAM-parsed plain contains non-Scripture pseudo-verses and structural material.**
   Commit `52b5d6592e23e9a02f88d4cd1a7340d06697572f`, “Add symmetric cross-links
   between mpplain and mpplus intros (Phases 19–21),” records pseudo-verses as a real
   plain-only format difference. `py/py_misc/mam_parsed_plus.py:_aps_to_chapter`
   removes `0` and `תתת`; plain retains them. The current documentation anchors are
   “Chapter structure” and “Verse structure” in
   `gh-pages/MAM-parsed/plain/html/mpplain.html`. Failure mode: contamination when a
   consumer treats every stored row and template parameter as Scripture. Audience:
   generic external consumers. Destination: embedded plain/plus notice and adjacent
   MAM-parsed documentation.

9. **MAM-simple exposes the same parashah break in three encodings.** Commit
   `cf7c7a3509632d87a6432ce0a67cfd39ad0733e4`, “Phase 1: land MAM-simple in
   MAM-basics,” brought the current XML guide and product here. A free marker plus the
   preceding verse's `ends-with-sampe` and the following verse's
   `starts-with-sampe` describe one break. The current documentation anchor is the
   sentence “MAM-simple has three encodings of each parashah break” in
   `MAM-simple/doc/reading-mam-simple-xml.md`. No repository defect was found; the
   remaining exposure is a naive counter. Failure mode: duplication. Audience: generic
   external consumers. Destination: embedded MAM-simple notice and adjacent
   documentation.

10. **The three codex entry indexes are locators, not manuscript transcriptions or
    Bible editions.** Commit `2979507a45b98ac33021e72144197f30ab0ee6d3`, “Take
    book-of-job's finer LC index records here too,” changed `in/lci_recs.json` while
    preserving the indexed Scripture span. Commit
    `d62646770330b4e3169b011647a45d28d46a000c`, “Scan-pages Phase 0: survey,
    tracked inventory, and the check lint,” records the distinction between
    letters-only page-edge locator evidence and pointed transcription. The Cambridge
    index's opening comment makes the same distinction, and Aleppo ranges and gaps can
    begin or end mid-verse. The current documentation anchors are “Records are captured
    from page-edge phrases, located in MAM's text” in `doc/scan-pages.md`, “Data” in
    `aleppo/README.md`, and “Data” in `cam1753/README.md`. Failure mode: category
    error. Audience: generic external consumers. Destination: embedded codex-index
    notices and adjacent documentation. The subordinate line-break and geometry files
    need adjacent warnings but no schema change.

## Resulting notice policy

The embedded notices should be short warning labels. MAM-parsed notices must say that
the payload is a dataset and that a consumer chooses a projection where a
choice-bearing structure occurs. MAM-simple notices must name only choices the simpler
product retains. Both must require role-aware recursion, fragment reassembly before
segmentation, and conditional mark-order guidance.

The codex-index notices must name the files as locator indexes, keep gaps and
mid-verse boundaries meaningful, and avoid a blanket promise about mark order in text
fields. The detailed rules, element schemas, and examples remain in adjacent public
documentation.
