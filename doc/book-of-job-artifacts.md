## Regeneration and verification

Run Book-of-Job generation from `C:/Users/BenDe/GitRepos/MAM-basics`:

```powershell
C:/Users/BenDe/GitRepos/MAM-basics/.venv/Scripts/python.exe py/main_gen_misc_authored_english_documents.py
```

Read the resulting Git diff. `git status --porcelain` is not reliable for this
tree: CRLF stat-cache noise has reported modified Book-of-Job artifacts whose
Git blobs did not change. Use this command instead:

```powershell
git diff --stat HEAD -- gh-pages/book-of-job/ book-of-job/out/
```

An output-neutral change leaves that diff empty. For an intended generated
change, inspect the changed HTML or JSON. An unexplained difference is a failure;
where it matters, compare the working file with its `HEAD` blob through
`git cat-file`.

Run the Book-of-Job checks from the same repository root:

```powershell
C:/Users/BenDe/GitRepos/MAM-basics/.venv/Scripts/python.exe py/check_all.py
```
