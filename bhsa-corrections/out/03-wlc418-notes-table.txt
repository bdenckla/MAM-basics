code 11, gccode p: We read punctuation in L differently from BHS.

code 13, gccode v: We read one or more vowels in L differently from BHS.

code 17, gccode K: We read one or more consonants in L differently from BHQ.
code 18, gccode M: Marks a word with a final consonant that is a medial (not a final) form.
code 19, gccode P: We read the punctuation in L differently from BHQ.
code 20, gccode Q: Marks a place where we agree with BHQ against BHS in reading L.
code 21, gccode U: We agree with both BHS 1997 and BHQ on an unexpected reading.
code 22, gccode V: We read one or more vowels in L differently from BHQ.
