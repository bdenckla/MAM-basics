Taamey D 1.0 source package
===========================

This package supplies Taamey_D-sources.zip from the Taamey D release snapshot
1.0-hbofonts-68cd62902202, renamed Taamey_D-1.0-sources.zip and otherwise
unchanged. The snapshot's provenance.json names its source commit,
68cd629022028ec648c0ee2f36ac0480123d0d47. SOURCE-INVENTORY.json records every
archive member's size and SHA-256.

Build-input scope
-----------------

font-m-TaD/Taamey_D-nofea.sym.sfd is the template of the editable glyph outlines.
font-m-TaD/Taamey_D.sym.fea is the template of the editable OpenType features.
font-m-TaD/license.sym.txt is the copyright/license template, and
font-m-TaD/license.txt is its expansion.
main_fill_in_template.py expands the three templates, using my_font_version.py,
which declares version 1.0, and my_open.py.
font-m-TaD/ffscript_generate_sfd_n_ttf.py uses FontForge to merge the features
into the outlines and emit SFD, TTF, WOFF, and WOFF2 files.
py/main_mega.py drives those steps.

Static inspection found no feature include files and no local imports outside
the archive on the generate-only path described below; the outlines and
features are entirely in the two templates.

Build procedure and dependencies
--------------------------------

From the directory into which the archive is extracted, the build is:

  python py/main_mega.py --generate-only

It fills the three templates, runs the FontForge script, and copies the WOFF2
to gh-pages/woff2/ under that directory. It finds FontForge through its
--fontforge option, on PATH, or, on Windows, as FontForgeBuilds/fontforge.bat
under ProgramFiles or ProgramFiles(x86), and on Windows it uses attrib to mark
the filled templates read-only. It therefore needs Python and a FontForge
installation with its Python module and WOFF2 support; these general-purpose
tools are not included. The other Python imports are standard-library modules:
argparse, hashlib, json, os, pathlib, shutil, string, subprocess, and sys.
Without --generate-only, py/main_mega.py goes on to documentation,
quality-assurance and release checks whose inputs are not in the archive; they
are not needed to build the font.

No build script was executed when this package was assembled. The archive does
not pin a complete build environment. The package has not been rebuilt or
tested for byte-for-byte reproducibility; the exact FontForge, compression-
library, and runtime versions used for the published WOFF2 have not been
established. FontForge regenerates the font from the included editable inputs;
reproducing identical binary bytes is not claimed here.

Binary association
------------------

The Taamey_D.woff2 that MAM-basics publishes is 22,264 bytes, version 1.0,
SHA-256 f17ec56ac2ef44a0f1e78b1d9adaaef6330ed1a1f9dec3d0ad1c87390e0dc151.
It is the Taamey_D/Taamey_D.woff2 member of the same snapshot's Taamey_D.zip,
SHA-256 be17640488ccd497908349114e8ea329bdd98aa4f59f6725cf4c2b278bfb3628.
The snapshot's provenance.json lists both archives and their members under one
source commit, and its SHA256SUMS.txt lists both archives. This association and
the static input review are the basis for providing this source package; they
are not a claim of an independently verified exact rebuild.

License and notices
-------------------

FONT-NOTICE.txt transcribes the copyright, GNU GPL version 2 grant, and font-
embedding exception from the font's OpenType name table, name ID 0. Only
whitespace on otherwise blank lines and the final newline differ from that
extracted text. Name ID 0 is the same in 1.0 as in 0.921.
GPL-2.0.txt is the full, unmodified GNU GPL version 2 text from
https://www.gnu.org/licenses/old-licenses/gpl-2.0.txt.

The source files retain their release bytes and notices. They are supplied as
the corresponding editable font source and build inputs under the font's GNU
GPL version 2 terms. No new GPL version 3 or CC0 grant is made over that
material, and the document-embedding exception is not a release from the
redistribution obligations for the font itself.
