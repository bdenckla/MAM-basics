# MAM-with-doc
Miqra According to the Masorah in HTML, with its documentation notes

MAM-basics publishes this edition at
https://bdenckla.github.io/MAM-basics/MAM-with-doc/.

The published sigil page at `../gh-pages/MAM-with-doc/sigil-decoding.html` is manually maintained as a
public-facing subset of `../doc/sigil-decoding.md`. It is not generated automatically from the Markdown
source, so updates should be merged carefully rather than replacing the HTML wholesale.
